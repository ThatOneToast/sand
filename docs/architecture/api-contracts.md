# Sand public API contracts

Status: implemented for issue #327

Sand's API contract system has four deliberately separate layers:

1. `sand-api-contract` owns the versioned serializable model, link-time
   registrations, duplicate-identity validation, deterministic ordering,
   lookup, search, module grouping, and JSON export.
2. `sand-macros::api` parses and validates author-written contracts. It derives
   the item kind, signature, and function parameter names, emits the static
   registration, and generates Rustdoc from the same prose.
3. `sand-api-enforce` audits the declared facade surface from build scripts.
   This second mechanism is required because a procedural attribute is never
   invoked for a missing attribute. A normal `cargo check` or `cargo build` of
   `sand` therefore rejects an uncontracted public declaration.
4. `sand-cli` queries only the catalog linked into that installed executable.
   It never parses source, calls GitHub, or accesses the network.

## Supported boundary

The compatibility boundary is the author-facing surface reachable through the
`sand` crate: root macros and `ResourceLocation`; `sand::prelude`; the curated
`cmd`/`command`, `event`, `item`, `inventory`, `predicate`, `state`, `entity`,
`participant`, `component`, `condition`, `execute_when`, `resource_ref`,
`version`, `vfx`, `systems`, `text`, `data`, and `vanilla` modules;
deliberately supported `advanced` hooks; feature-gated resource-pack and system
APIs; and author-facing APIs generated by Sand macros.

Prelude and alternate topic paths are aliases of a canonical identity. Direct
public visibility in implementation crates is not by itself a support promise.
`sand::__private`, `#[doc(hidden)]` generated helpers, compiler inventory
records, and export wiring are excluded.

`sand/api-surface.txt` is the checked-in, exact list of facade re-export
declarations whose contracts must be forwarded/generated because stable Rust
does not permit attaching the contract attribute to a `pub use`. It is not a
wildcard skip list: a new public declaration is absent and fails the build-time
audit until its contract is added. Definitions owned directly by the facade use
`#[api]`.

## Canonical identity and availability

Canonical paths begin with `sand::`. Aliases are sorted and must not collide
with another canonical path or alias. Entries and set-like fields are sorted
before export; declaration-ordered fields such as parameter descriptions and
use guidance retain their authored order. The export contains schema version,
Sand package version, availability strings, and no timestamps or source paths.

Feature and `cfg` availability is part of each contract. Cargo's supported
feature matrix must be built to exercise gated registrations; inactive items do
not appear in a binary built without their feature.

## Stable-Rust enforcement

The attribute validates present contracts: required fields, unknown and
duplicate keys, item form, documented parameter names, required parameter and
return descriptions, paths, aliases, and lists. The build auditor covers the
absence case during the ordinary Cargo path. Its subprocess fixture runs
`cargo check` against a crate containing an unannotated public function and
asserts that compilation fails with the canonical API path and source line.

Narrow exclusions are recognized only for non-public visibility,
`#[doc(hidden)]`, and `__private`. Generated/forwarded facade identities must
appear exactly in the checked-in surface table and in facade-owned metadata.

## CLI behavior

- `sand api show <path>` resolves canonical paths and aliases and prints every
  contract field. Unknown paths receive deterministic edit-distance
  suggestions.
- `sand api search <query>` requires every query word to match and ranks path,
  alias, summary, parameters, guidance, and Minecraft behavior with fixed
  lexical weights; canonical path breaks ties.
- `sand api module <module>` groups direct children by API kind and reports
  nested modules separately.
- `sand api export` writes deterministic schema-versioned JSON to stdout;
  `--output` writes the identical bytes to a file.

Large tutorials remain in the book. Contract prose describes the individual
Rust API and its Minecraft meaning.
