## Build-time check

The repository benchmark helper was run five times per scenario on this branch
and on the starting commit, using the same machine and toolchain. Touching the
macro implementation before `cargo check --workspace` moved the median from
7.059s to 7.709s (+9.2%). Touching the API-contract declarations moved it from
7.102s to 7.670s (+8.0%). The samples were tight, so this is a real, modest
cost from the larger generated surface—not a performance win. It stays below a
10% regression in both representative rebuilds.
