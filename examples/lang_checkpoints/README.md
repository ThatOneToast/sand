# Scout checkpoints

Sneak while using a carrot on a stick to save your Overworld position. Use it
normally to return to that position with a five-second cooldown. The checkpoint
and cooldown belong to each player. A private boss bar shows the remaining
cooldown after returning to camp.

```sh
sand lang build examples/lang_checkpoints
```

The package includes the bundled Spatial and Time libraries as ordinary Sand
modules. Use `sand lang add spatial` and `sand lang add time` to add them to a
new package.
